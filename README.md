## Iris_classification

# Описание программы
Данная программа реализует задачу многоклассовой классификации на знаменитом датасете Iris (Ирисы Фишера) с использованием библиотеки глубокого обучения PyTorch.

# Цель
Здесь решается задача классификации видов ирисов на основе их морфологических характеристик.

# Задачи
1. Построить модель, классифицирующую три вида ирисов (setosa, versicolor, virginica)
2. Оценить точность модели на тестовых данных
3. Получить интерпретируемые результаты предсказаний

# Структура программы
1. библеотеки: PyTorch, scikit-learn, NumPy
2. Загрузка и подготовка данных (EDA - исследовательский анализ данных)
3. Препроцессинг данных
4. Архитектура нейронной сети: класс NeuralNetwork
5. Инициализация и обучение модели
6. Оценка модели
